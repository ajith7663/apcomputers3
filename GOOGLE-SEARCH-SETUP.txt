3. Complete the verification method Google offers. For GitHub Pages, HTML tag verification is usually easiest: copy the exact meta verification tag from Search Console and add it inside the <head> of index.html, then commit and click Verify. Do not invent a verification token.

5. Use URL Inspection to request indexing for the homepage and important service pages. Indexing is not guaranteed or immediate.
